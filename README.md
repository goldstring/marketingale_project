## Overview

Marketingale is a digital marketing agency website developed as a freelance project. The project was created based on the client's requirements and provided UI mockups.

The website focuses on presenting the company's digital marketing services and online presence with a responsive and modern interface.

## Technologies Used

* Laravel
* PHP
* MySQL
* Bootstrap 5
* jQuery
* JavaScript
* Push Notifications
* Email Integration

## Project Requirements

The client required a professional company website that could:

* Present the company's digital marketing services
* Provide a responsive and modern UI
* Follow the UI design provided through client mockups
* Showcase the company's online presence
* Support email integration
* Support push notifications

## Development

The website UI was developed according to the mockup images provided by the client. Laravel was used for the backend and application structure, while Bootstrap 5, jQuery, and JavaScript were used for the frontend.
